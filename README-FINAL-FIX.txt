AWAPART66 v266 - kandidat perbaikan, bukan rilis teruji.
Paket sumber web/Android berasal dari v265 unified; installer hanya mengganti backend yang hash-nya dikenal dan account-email.js, bukan seluruh website. Tidak mengubah .env, Nginx, database atau Google Login. Backup database dibuat; rollback kode otomatis jika health gagal. Jangan restore database setelah transaksi baru.
Customer baru otomatis menerima verifikasi. Customer lama menggunakan verifikasi dengan password sebelum reset; akun admin/owner lama wajib konfirmasi kepemilikan email satu kali. Tidak memaksa recovery_enabled. Super admin yang menerima email harus menekan tombol konfirmasi pada halaman tautan, bukan sekadar membuka email. Setelah itu reset dari luar tanpa password lama. Jika email lama belum dipercaya dan password hilang, gunakan pemulihan identitas oleh pengelola berwenang, bukan bypass.
Uji staging terlebih dahulu dengan pengelola server; installer produksi sengaja tidak menyentuh staging. Uji registrasi, konfirmasi, reset semua role, token sekali pakai, login, booking, keuangan. APK Android unified memakai web produksi. Untuk build, unggah isi android/ ke root repo Android yang sudah ada, jalankan workflow v266 dengan release=true dan signing secrets yang sudah tersedia. APK/AAB belum dibangun di sini. Jangan publikasi sebelum semua uji lulus. Akun publikasi dikelola orang dewasa berwenang.
